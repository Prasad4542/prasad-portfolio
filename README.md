# Prasad Mundhe — Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Before deploying

1. Put your final resume at:
   `resume/Prasad_Mundhe_Resume.pdf`
2. Replace the placeholder LinkedIn URL in `index.html`.
3. Replace the placeholder GitHub URL in `index.html`.
4. Replace `your-email@gmail.com` with your real email.
5. In the contact form, change:
   `https://formsubmit.co/your-email@gmail.com`
   to your real email.

## Run locally

Open `index.html` in a browser, or use VS Code + Live Server.

## Deploy on GitHub Pages

```bash
git init
git add .
git commit -m "Create portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/prasad-portfolio.git
git push -u origin main
```

Then open the GitHub repository:
Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.

## Custom domain

After GitHub Pages is working, a custom domain can be connected from:
Settings → Pages → Custom domain.

## Notes

The project uses Google Fonts and Font Awesome CDN links, so those resources require an internet connection.
